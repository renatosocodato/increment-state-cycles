# Increment-state cycles: reproducible calculations and figures

This research package accompanies the manuscript “Increment-state cycles do not determine physical reversibility”. It contains the mathematical calculations, saved synthetic simulation summaries and individual-study outputs, and R source for the five main figures. All saved data are generated by the models in this package; no microscopy, individual animals, cells, or experimental trajectories are included. A prospective microglial application in the manuscript is not experimental validation of the synthetic models. The separate range-theory project is not part of this package.

## Computational environment

The files were prepared and tested in Python 3.14.7, NumPy 2.3.5, SciPy 1.16.3, pandas 2.3.3, SymPy 1.14.0 and R 4.5.2. The R figures use ggplot2 4.0.2, cowplot 1.2.0, svglite 2.2.2, ragg 1.5.0 and jsonlite 2.0.0. Cairo and an installed, appropriately licensed Arial font are required to reproduce the vector typography. Numeric results are portable within usual floating-point tolerance; vector files can differ bytewise across R, Cairo, font, and operating-system versions. These requirements describe the tested current environment, not a guarantee of bitwise reproduction on all platforms.

In a virtual environment install Python dependencies with `python -m pip install -r requirements.txt`. In R install `ggplot2`, `cowplot`, `svglite`, `ragg`, and `jsonlite`. Scripts use paths relative to their own location. Run from a writable copy: several generation scripts overwrite their saved tables and figure files. Use a single CPU thread for the simulation: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1`.

`DATA_DICTIONARY.md` maps every saved table and its columns to their scientific role.

## Verify published numerical results

From this directory run `python3 run_checks.py`. This reads the saved data and checks the exact pair examples, reconstruction of simulation summaries, the classification channel, and the finite physical model. It does not rerun large Monte Carlo jobs. For the symbolic recovery and asymmetric-error studies, the calibration trajectories themselves are not saved: these checks reconstruct exceedance rates conditional on the stored cutoffs, whereas full regeneration recalculates the cutoffs from the recorded random streams. `python3 test_checks.py` runs negative controls on temporary copies to ensure missing outputs, empty summaries and a corrupted pair matrix are rejected. `published_figures/Figure_1.pdf` through `Figure_5.pdf` are the exact vector PDFs included in the manuscript proof; their SHA-256 digests are recorded in `SHA256SUMS`.

## Recreate the five main figures from the supplied saved tables

Run each command from the repository root:

```sh
Rscript versao_expandida_20261117/figures_r/render_physics_figures.R
Rscript versao_expandida_20261117/extensao_misturante_20261117/render_mixing.R
Rscript versao_expandida_20261117/erro_assimetrico_20261117/render_error.R
Rscript versao_expandida_20261117/calibracao_independente_20261117/render_calibration.R
Rscript recuperacao_fisica_20261118/figura_fisica.R
```

These scripts write next to themselves. The five corresponding outputs are `figures_r/Figure_1.pdf`, `extensao_misturante_20261117/Figure_mixing.pdf`, `erro_assimetrico_20261117/Figure_asymmetric_error.pdf`, `calibracao_independente_20261117/Figure_calibration.pdf` and `recuperacao_fisica_20261118/Figure_physical.pdf`; paths under `versao_expandida_20261117/` are abbreviated in that list. The first R script also renders earlier exploratory Figures 2 and 3 in its own directory, which are not the manuscript Figures 2 and 3. The five PDFs and SVGs in `published_figures/` are not overwritten. The five R scripts were executed in the preparation environment; the regenerated PDFs matched the manuscript figure PDFs pixel-for-pixel when rendered at 120 dpi.

## Regenerate data (optional; overwrites saved outputs)

The model and output are described in the manuscript and supplemented by the assumptions below. Work on a copy and execute in order:

```sh
python3 versao_expandida_20261117/figures_r/exact_word_laws.py
python3 versao_expandida_20261117/extensao_misturante_20261117/mixing_exact.py
python3 versao_expandida_20261117/recuperacao_finita_20261117/finite_recovery.py
python3 versao_expandida_20261117/erro_assimetrico_20261117/asymmetric_exact.py
python3 versao_expandida_20261117/erro_assimetrico_20261117/exploratory_pause.py
python3 versao_expandida_20261117/erro_assimetrico_20261117/finite_error.py
python3 versao_expandida_20261117/calibracao_independente_20261117/synthetic_calibration.py
python3 versao_expandida_20261117/calibracao_independente_20261117/prepare_plot.py
python3 recuperacao_fisica_20261118/estudo_fisico.py
```

The independent-study counts and lengths can make these jobs substantially more expensive than `run_checks.py`. Run one numerical job at a time. `python3 verify_regeneration.py` copies the package into a temporary directory, reruns the numerical generators and removes each expected output before rerunning its producer and compares the resulting CSV and rotor JSON files to the saved files within tolerance; it may take longer than the read-only checks. Each generator has a 300-second limit; on slower machines, set the positive integer `EPJE_JOB_TIMEOUT_SECONDS` to an appropriate finite limit. Fixed root seeds are 20261117 (finite symbolic recovery), 20261118 (asymmetric error), 20261119 (synthetic calibration), and 2026111803 (physical-rotor recovery). Streams and parameters are specified by the scripts; the rotor uses 600 calibration studies and 600 independently tested studies per model per length, with 24 trajectories per study. Lengths are nested prefixes, not independent replications. Channel-calibration results use 200 studies per condition with 200 block-bootstrap replicates. The supplied `studies.csv`, trajectory tables and summaries are outputs of these runs, not independent biological measurements.

## Scientific assumptions and limits

- E and R label the signs of increments of an even coordinate; P is unchanged by time reversal and E/R are exchanged. The stationary pair classification assumes matched consecutive pair marginals. Finite tracks have the boundary term in the manuscript.
- The cycle/reset and replacement channels are prescribed finite-state models; the data are synthetic. A model-specific null, finite trajectory lengths, and overlapping windows cannot establish an experimental false-positive rate or microscopic entropy production.
- Asymmetric classification can produce a nonzero observed contrast for a reversible latent control. Inverse-channel calculations assume an invertible, stable, time-independent classification channel applied independently at the symbol positions and independently paired reference labels.
- The continuous-time rotor has a two-level marker and a constructed matching point; its three-position and increment-pair laws match a chosen equilibrium comparator, not all equilibrium processes. No parameter was fitted to a cell.
